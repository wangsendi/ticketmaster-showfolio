# 验证说明

测试使用合成账号、本地 HTTP 响应和临时 SQLite 数据库，不需要真实账号、代理凭据或生产数据库。

```bash
python3 -m pip install -r requirements.txt
npm ci
npm run install:cloakbrowser
npm run install:chromium
npm run install:firefox
npm test
npm run check
```

Linux 需要安装 Xvfb 和浏览器系统依赖。有头预检只打开本地页面，不访问账号服务。

## 覆盖范围

- CSV、TSV、TXT、XLSX 解析，成功及需人工处理行跳过，账号数量与并发参数校验。
- 多批次并行、独立停止与重试队列、运行中调整并发、持续重试及重启恢复。
- 代理独占租用、池刷新、代理不足时等待、失败后换节点以及取消等待。
- SQLite 写入串行化、事务回滚、并发读取、截图与结果持久化。
- 浏览器子进程隔离、停止和超时、崩溃分类、延迟登录表单及访问暂停页识别。
- CloakBrowser 适配后的 HAR 响应内容、Cookie、整页截图和运行时驱动选择。
- Excel 后台生成、重复请求合并、下载 Range、文件到期清理及异常后的任务恢复。
- 单个 XLSX 中的账号与图片对应关系、密码文本格式、超长 Cookie 续列、XML 非法字符处理。
- 截图自适应压缩与文件大小限制，数据库原图不变；CSV 和原图 ZIP 导出。

## 验证边界

自动化测试验证应用行为，不证明外部网站或任意代理始终可用。网站验证码、身份校验和访问暂停页会终止该账号的自动查询；成功或需人工处理的账号不会被重试流程重新提交。

Excel 通过工作簿回读、内部图片及 XML 检查验证；仍建议在实际使用的 Excel / WPS 版本中确认长截图的显示效果。

不要将真实测试账号、网络诊断报告、导出文件、截图、浏览器会话或数据库提交到仓库。

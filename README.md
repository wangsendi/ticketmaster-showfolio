# Ticketmaster Showfolio

本地运行的演出报名查询工作台。导入账号表格，查询活动的已选场次，查看整页截图，并导出包含账号资料与截图的单个 Excel。账号、密码、Cookie、场次和原始截图保存在本机 SQLite 中。

## 启动

需要 Python 3.11+、Node.js 20.19+ 或 22.12+；Linux 需要 Xvfb 和浏览器系统依赖。

```bash
python3 -m pip install -r requirements.txt
npm ci
npm run install:firefox
python3 web.py --host 127.0.0.1 --port 8088
```

打开 <http://127.0.0.1:8088>。`npm start` 和 `python3 run.py` 也可启动服务。

默认使用 Playwright Firefox，无需额外传入浏览器参数。也可选择 Chromium、Google Chrome 或 CloakBrowser；CloakBrowser 需先执行 `npm run install:cloakbrowser`，使用固定的 Chromium 146.0.7680.177.5 并关闭自动更新，安装至 `data/browser-cache`。仓库不包含浏览器二进制文件。

账号详情和导出文件会显示完整密码及 Cookie。默认仅监听本机；需要从局域网访问时，可自行指定 `--host 0.0.0.0`。

## 使用

1. 在页面下载模板，填写邮箱、密码；上传 CSV、TSV、TXT 或 XLSX，选择活动地址和并发数。
2. 点击“更新全部地区代理”，完成后点击“开始查询”。服务重启后需要再次手动更新代理。
3. 可导入、同时运行多个批次。每批独立控制并发、停止、失败重试和持续重试。
4. 查询完成后查看账号的已选场次、Cookie 和整页截图；“下载原图”保留原始分辨率。
5. 点击“导出 Excel（含截图）”，后台生成单个 `.xlsx`，页面显示进度，完成后下载。

账号数量与填写的并发数不设固定上限；实际浏览器数量受各批次设置、账号数和可用代理数约束。所有批次共用代理池，同一出口 IP 严格只允许一个浏览器使用（即使来自不同节点），不足时等待。运行中可调整当前批次并发；调低不会中断已开始的账号。账号取得出口后会按启动间隔依次启动浏览器，此时显示“等待启动浏览器”；只有尚未取得出口时显示“等待空闲出口 IP”。

### 导入格式

- 英文列名 `email,password` 或中文 `邮箱,密码`；列顺序不限。无表头时，前两列分别为邮箱、密码。
- CSV、TSV、TXT 使用 UTF-8；TXT 使用 Tab 分隔。CSV、TSV、TXT 最多 5 MB，XLSX 最多 50 MB。
- Excel 密码列使用文本格式；数值、公式、空密码及同一表格中的重复账号会被拒绝。
- 可设置“最多导入账号”，留空表示全部。表格中已成功或需人工处理的行不占名额。
- `status`、`状态`、`查询状态` 为 `success`、`已完成`、`成功`、`needs-human`、`需人工验证`、`需要人工验证` 的行会跳过，兼容大小写及前后空格。

### 重试与状态

每个账号每轮只尝试一次登录。持续重试会将失败账号放到队尾，重新等待可用代理；停止任务或关闭开关后结束。重试尽量避开上次节点与相同出口，只有一个可用出口时允许在后续轮次复用。

登录回调完成并返回活动页后，若报名接口的登录核验迟迟未完成，会保留当前会话刷新活动页，最多三次；每次重新核验账号和 Cookie，账号不匹配则停止。登录完成后，场次解析不完整不妨碍保存已核验页面的整页截图。截图超时会先在当前页面重试一次，仍超时再刷新页面，最多刷新三次；刷新后重新确认登录状态。

明确出现 Persona 身份认证要求时，账号标为“已完成”，场次显示“未进行身份验证”，保留验证页面截图；此标记不用于账号密码或普通验证码。`Browsing Activity Paused` 标为失败，可重新排队。其他验证码或人工验证要求标为“需要处理”，可通过人工处理重试入口重新查询，不参与持续重试。

网站明确返回登录凭据不匹配（包括 HTTP 200 内的业务错误）时，标为“已完成”，场次显示“账号密码错误”，保留错误页面截图，不参与持续重试，也不扣代理置信度。明确的用户不存在、密码重置要求、密码格式校验失败，或密码为 7 位且登录按钮不可用，同样标为“已完成”，在场次栏写明原因并停止持续重试。这些账号异常不影响代理置信度。HTTP 401、403、404、409 或回调超时本身不代表账号或密码错误。历史失败记录在服务下次启动时按已保存的明确证据更新状态。

失败账号可以在其他账号运行时立即排队重试，结果覆盖原记录，不保留额外的重试副本。停止单批不影响其他批次；删除任务会移除该批次及其账号、Cookie、截图，运行中的批次需先停止。

### 导出

- 默认导出一个包含全部账号、明文密码、完整 Cookie、场次、状态和内嵌截图的 XLSX，不自动拆分或额外打包。
- 文件严格控制在 100 MB（100,000,000 字节）以下，按截图数量分配预算，必要时降低图片质量和分辨率，保留整页内容、不裁切。细字可能变糊，数据库原图不变。
- 若账号文字资料本身超限，会明确报错，不截断账号、密码或 Cookie。超长 Cookie 使用续列完整保存。
- 后台串行生成，重复点击会复用正在生成的任务；下载支持 HTTP Range。私有临时文件一小时后或服务停止时清理。
- CSV 和原始截图 ZIP 接口仍可使用：`/api/batches/{id}/export`、`/api/batches/{id}/export.zip`。

## 代理

默认连接本机 OneSocks 节点接口 `http://127.0.0.1:10802/api/nodes`，从同服务的 `/api/config` 读取 SOCKS 入口与连接配置。

- “更新全部地区代理”读取接口已有 IP 检测 JSON，接纳所有国家和地区，不按国家筛选；跳过检测失败、缺失 IP 或格式无效的节点。
- 查询和重试复用现有名单，不自动刷新，不回退直连。手动更新保留正在使用的连接，新尝试等待更新完成。
- 节点置信度初始为 10，失败减 1，成功恢复为 10；降为 0 后按节点禁用，不自动恢复，也不会因正在执行的查询成功而恢复。
- 打开代理页面 `/proxies` 查看节点、出口 IP、占用和置信度，可手动恢复单个节点或一键恢复全部禁用节点。同 IP 占用限制独立于节点禁用状态。
- 活动深度检测生成的代理池仅用于对应活动。

可独立生成诊断报告，报告仅保存在本机：

```bash
python3 proxy_check.py --out config/proxy-all.json
# 诊断时可选：--country US
```

## 浏览器配置

可选 `cloakbrowser`、`chromium`、`firefox`、`chrome`。启动时可以指定浏览器：

```bash
npm run install:firefox
npm start -- --host 0.0.0.0 --port 8088 --browser firefox
# 或 python3 web.py --host 0.0.0.0 --port 8088 --browser firefox
```

`--browser` 优先于配置文件，仅影响本次服务及其新建查询浏览器，不修改配置文件。不传该参数时，`data/browser.json` 优先于环境变量 `TM_BROWSER`，修改后对新启动的浏览器生效，已经打开的浏览器继续执行。

```bash
mkdir -p data
cp config/browser.example.json data/browser.json
```

没有运行时设置文件时，使用 `TM_BROWSER`；未设置时默认 Firefox。可选浏览器安装命令：`npm run install:chromium`、`npm run install:firefox`。Google Chrome 需要单独安装。缺失依赖会明确报错，不自动回退。

## 本地数据与隐私

默认数据库为 `data/ticketmaster.sqlite3`，包含账号密码、Cookie、截图及查询日志。数据库使用 WAL；服务运行时不要单独删除 `-wal`、`-shm`。备份应停止服务后复制，或使用 SQLite backup API。

查询中间文件位于私有临时目录，结果写入数据库后清理。正常停止会结束浏览器，意外退出后未完成任务标为中断，由用户手动继续。

`.gitignore` 排除账号表格、数据库及事务文件、代理报告、环境配置、导出、截图、HAR、日志、浏览器缓存及会话数据。仓库仅保留代码、合成测试和不含凭据的配置示例；提交前仍应审查暂存区。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `web.py` / `run.py` | Web、API 与启动入口 |
| `accounts.py` | 表格解析与校验 |
| `store.py` | SQLite 事务与持久化 |
| `jobs.py` | 多批次调度、并发、停止与重试 |
| `runner.py` | 独立浏览器进程及崩溃、超时处理 |
| `results.py` / `verify.py` | 登录结果与场次核对 |
| `export_jobs.py` / `exports.py` | 后台导出、截图压缩与文件大小控制 |
| `proxy_pool.py` / `proxy_check.py` | 代理租用、筛选与检测 |
| `src/` | 浏览器适配、登录导航、代理桥与长截图 |
| `templates/` / `static/` | 无需前端构建的查询界面 |
| `tests/` | 本地合成数据与回归测试 |

旧文件批次可通过 `migrate_history.py` 导入，需要匹配的本地账号表格；重复导入会跳过，原文件不删除。详见 `python3 migrate_history.py --help`。
